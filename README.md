## Get started

```sh
git clone https://github.com/Up-to-code/My-contact-card.git
cd My-contact-card
```

Serve the static files locally, then open http://127.0.0.1:8080.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```
